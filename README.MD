# Docker Security Assessment & Demonstration

Проект демонстрирует различие между защищенным и уязвимым Docker-контейнерами в одной виртуальной сети.

## Отчет по безопасности

Я развернул в Docker два сервиса в одной виртуальной сети: первый — это Telegram-бот, который я максимально защитил, а второй — обычный веб-сервер с популярными ошибками в безопасности. Чтобы все проверить, я настроил бота как инструмент аудита: прямо из чата Telegram через команды `/whoami`, `/test_write` и `/check_socket` можно убедиться, что бот работает от обычного пользователя `appuser`, а его диск заблокирован на запись (`read-only`).

Главный вывод работы в том, как легко можно взломать незащищенный сервис. Второму сервису случайно дали доступ к файлу `/var/run/docker.sock` и запустили от `root`. Из-за этого хакер, проникнув во второй сервис, может через сокет Docker отдать команду на создание нового контейнера с монтированием всего диска компьютера и полностью захватить сервер. Мой защищенный бот от такой атаки полностью закрыт, потому что у него нет прав `root`, сокета и возможности менять файлы.
